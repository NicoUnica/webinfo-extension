WebInfo — Privacy Policy

Last updated: August 3, 2026

Overview

WebInfo is a browser extension that shows the server country flag and IP geolocation of the websites you visit. It is designed to collect as little data as possible.

Data we process

The extension processes only the following:

  • Website hostname / server IP: The hostname (or resolved IP) of the site in your active tab is sent to the geolocation API to look up its server location — country, city, coordinates, ASN and ISP. This is the location of the website's server, not your own location.

Data we do NOT collect

  • Personal information (name, email, etc.)
  • Browsing history
  • User activity (clicks, scrolling, keystrokes)
  • Page content, form fields or cookies
  • Passwords or financial information

How data is used

Lookup results are only used to display information inside the extension. They are cached in the browser's session storage and cleared automatically when the browsing session ends. Nothing is stored on a permanent server on your behalf.

Third-party services

To perform a lookup, the extension contacts the following services:

  • ipwho.is — receives the hostname or server IP and returns geolocation details. It may forward the IP address to the geolocation provider ipapi.is. Only the IP address is forwarded — never your identity, page content or hostname beyond what is needed for the lookup.
  • cloudflare-dns.com — used for DNS-over-HTTPS to resolve a hostname to an IPv4 address when needed.
  • map.bluecdn.com — serves the map preview image.

Data attribution

Fallback geolocation databases are attributed as required by their licenses:

  • IP Geolocation by DB-IP (DB-IP Lite, CC BY 4.0)
  • GeoLite data by MaxMind
