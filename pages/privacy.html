WebInfo — Privacy Policy

Last updated: August 20, 2026

Overview

WebInfo is a browser extension that shows the server country flag and IP geolocation of the websites you visit. It is designed to collect as little data as possible.

Data we process

The extension processes only the following:

  • Website hostname / server IP: The hostname (or resolved IP) of the site in your active tab is sent to the geolocation API to look up its server location — country, city, coordinates, ASN and ISP. This is the location of the website's server, not your own location.

Data we do NOT collect

  • Personal information (name, email, etc.)
  • Browsing history
  • User activity (clicks, scrolling, keystrokes)
  • Page content, form fields or cookies
  • Passwords or financial information

How data is used

Lookup results are only used to display information inside the extension. They are cached in the browser's session storage and cleared automatically when the browsing session ends. Nothing is stored on a permanent server on your behalf.

Third-party services

To perform a lookup, the extension contacts the following services:

  • ipwho.is — receives the hostname or server IP and returns geolocation details. It may forward the IP address to the geolocation provider ipapi.is. Only the IP address is forwarded — never your identity, page content or hostname beyond what is needed for the lookup.
  • cloudflare-dns.com — used for DNS-over-HTTPS to resolve a hostname to an IPv4 address when needed.
  • host.tools — receives the hostname to look up its SSL certificate details (issuer and validity dates).
  • who-dat.as93.net — receives the hostname to look up its public WHOIS registration details (registrar, creation and expiry dates).
  • tile.openstreetmap.org (OpenStreetMap) — serves the map preview image tiles for the server's location.

Data attribution

Fallback geolocation databases are attributed as required by their licenses:

  • IP Geolocation by DB-IP (DB-IP Lite, CC BY 4.0)
  • GeoLite data by MaxMind

Changes

This privacy policy may be updated from time to time. Any changes will be published on this page.

WebInfo — Política de privacidad

Última actualización: 20 de agosto de 2026

Resumen

WebInfo es una extensión de navegador que muestra la bandera del país del servidor y la geolocalización por IP de los sitios web que visitas. Está diseñada para recopilar la menor cantidad de datos posible.

Datos que procesamos

La extensión solo procesa lo siguiente:

  • Nombre de host del sitio / IP del servidor: el nombre de host (o la IP resuelta) del sitio en tu pestaña activa se envía a la API de geolocalización para consultar la ubicación de su servidor: país, ciudad, coordenadas, ASN e ISP. Esta es la ubicación del servidor del sitio web, no tu propia ubicación.

Datos que NO recopilamos

  • Información personal (nombre, correo electrónico, etc.)
  • Historial de navegación
  • Actividad del usuario (clics, desplazamiento, pulsaciones de teclas)
  • Contenido de la página, campos de formulario o cookies
  • Contraseñas o información financiera

Cómo se usan los datos

Los resultados de las consultas solo se usan para mostrar información dentro de la extensión. Se almacenan temporalmente en el almacenamiento de sesión del navegador y se borran automáticamente cuando finaliza la sesión de navegación. No se guarda nada en un servidor permanente en tu nombre.

Servicios de terceros

Para realizar una consulta, la extensión contacta con los siguientes servicios:

  • ipwho.is — recibe el nombre de host o la IP del servidor y devuelve los detalles de geolocalización. Puede reenviar la dirección IP al proveedor de geolocalización ipapi.is. Solo se reenvía la dirección IP, nunca tu identidad, el contenido de la página ni el nombre de host más allá de lo necesario para la consulta.
  • cloudflare-dns.com — se usa para DNS sobre HTTPS para resolver un nombre de host a una dirección IPv4 cuando es necesario.
  • host.tools — recibe el nombre de host para consultar los detalles de su certificado SSL (emisor y fechas de validez).
  • who-dat.as93.net — recibe el nombre de host para consultar sus datos públicos de registro WHOIS (registrador, fechas de creación y de expiración).
  • tile.openstreetmap.org (OpenStreetMap) — sirve las imágenes de los mosaicos del mapa de vista previa de la ubicación del servidor.

Atribución de datos

Las bases de datos de geolocalización de respaldo se atribuyen según lo exigen sus licencias:

  • IP Geolocation by DB-IP (DB-IP Lite, CC BY 4.0)
  • GeoLite data by MaxMind
