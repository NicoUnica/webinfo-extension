# WebInfo

[![Chrome Extension](https://img.shields.io/badge/Chrome-Extension-green.svg)](https://chrome.google.com/webstore)
[![Manifest V3](https://img.shields.io/badge/Manifest-V3-blue.svg)](https://developer.chrome.com/docs/extensions/mv3/intro/)

Extensión de Chrome para ver información de servidores web con banderas de países.

## Características

- Banderas de países en la barra de herramientas
- IP, ASN, ISP, ciudad y zona horaria
- Información SSL y WHOIS
- Mapa de ubicación del servidor
- Interfaz en inglés y español

## Instalación

1. Abrir `chrome://extensions`
2. Activar **Modo desarrollador**
3. Clic en **Cargar descomprimida**
4. Seleccionar este directorio
